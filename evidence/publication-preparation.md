## Hosted adaptation

- Vite builds the existing browser experience and a Cloudflare Worker server. Direct route requests render their own content and metadata; unknown routes return 404.
- The same preview-request validator is shared by the Node and hosted servers. The hosted server stores only an anonymous allowlisted configuration receipt in D1. It hashes the status token, rejects conflicting retries and does not retain names, email, phone, free text or consent choices.
- The D1 schema is checked in under `drizzle/` and generated from `db/schema.ts`. There are no seed records or runtime schema writes.
- The public origin points to the registered ChatGPT Site. Search indexing stays disabled for this review publication.
- The optional browser WebMCP tool reads only a saved anonymous configuration. It cannot send an inquiry or make a commercial decision.
